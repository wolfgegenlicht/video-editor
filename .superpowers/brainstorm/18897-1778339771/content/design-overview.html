Multi-select Design Overview

Four ways to select, one unified selection set. Does this match your vision?

Selection mechanisms

① Cmd+click on item
Toggles that item in/out of selection. Existing selection preserved. Works on any item type.
② Rubber-band drag
Drag on empty timeline background → blue selection rect. All items whose time range intersects the rect get selected on mouseup.
③ Track label click
Click the label strip on the left of any track → selects ALL items in that track. Cmd+click label adds/removes that track's items.
④ Shift+click track label
Click label on track 1, Shift+click label on track 3 → selects all items in tracks 1, 2, and 3.

Movement

Drag any selected item → all selected items shift by the same time delta, each staying in its own track. Uses existing *Live() pattern during drag, commits to history on mouseup.

Properties panel

Single item selected → normal properties as today. Multiple items selected → panel shows "N items selected" (no properties). Plain click without Cmd clears multi-select and restores normal single-select behavior.
Approach A — parallel selection layer
Existing selectedClipId, selectedOverlayId etc. stay untouched for the Properties panel. New selectedItemIds: Set<string> added to store for multi-select. Low regression risk.
